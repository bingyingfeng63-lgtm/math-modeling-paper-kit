# 提交前最小验收清单

> 用法：每届完稿后逐项勾选。赛事特定数值（页数、大小、查重率）以 `02-华数杯规则层/` 或当届官方文件为准。

## 首页与匿名

- [ ] 组别、队号、正式论文题目、摘要、关键词齐全。
- [ ] 摘要不超过第一页；正文从第二页开始且无目录。
- [ ] 全文（正文与附录）无姓名、学校等身份信息。

## 编号与交叉引用

- [ ] 公式、图、表编号连续。
- [ ] 所有 `REF` 域可正确更新，无「Error: Reference source not found」。
- [ ] 图题在下、表题在上，编号口径全文一致。

## 数值一致性

- [ ] 图表数值、正文数值与当前代码 / 数据表输出一致。
- [ ] 单位、时段、样本量、场景和精度统一。
- [ ] 不写「全局最优」「完全正确」等超出证据的表述。

## 文献与 AI 声明

- [ ] 文献逐条有正文引用，引用逐条有文末来源。
- [ ] AI 声明、AI 参考条目、附录详情、代码注释和图表标识完整真实。

## 占位符与终检

- [ ] 无 `xxxx`、`TODO`、示例句、错误引用或其他占位符。
- [ ] 导出最终 PDF 后逐页检查字体、公式、表格、图片、页码和分页。
- [ ] 论文与支撑材料均匿名、命名正确、大小合规，并保留可复现代码和必要输出。
