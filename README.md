# 数模论文写作工具包（math-modeling-paper-kit）

一套可跨届复用的「数学建模论文写作」规范与工作流模板。把「赛题—代码—结果」翻译成「能写什么、不能写什么、怎么规范排版」，并给出提交前验收清单。

## 为什么做这个

数模论文的痛点不是「不会建模」，而是：写完才发现公式没交叉引用、图表编号乱、结果和代码对不上、AI 声明缺失、占位符残留。本仓库把这些经验固化成可复用的规范 + 模板，每届比赛直接 clone 套用。

## 目录导览

| 目录 / 文件 | 作用 |
|---|---|
| `01-通用写作规范/通用数模论文写作规范.md` | 跨赛事通用的写作规范（闭环、公式、图表、排版、引用、语言、复盘方法） |
| `02-华数杯规则层/华数杯格式规则.md` | 赛事特定硬规则（页数、字号、查重率、提交格式），换比赛只换这一层 |
| `03-验收清单/提交前最小验收清单.md` | 提交前逐项勾选的 checklist |
| `04-写作工作流模板/` | 三个可复制的工作流模板：核验报告、证据清单、阅读指南 |
| `05-官方模板获取指引.md` | 官方模板 / 章程从哪下载（不转发原文件） |

## 每届怎么用（推荐流程）

1. **建项目**：复制本仓库到一个新目录（或 `git clone` 后另开分支）。
2. **对规则**：下载当届官方模板与章程，对照 `02` 规则层更新赛事特定数值。
3. **写核验报告**：复制 `04/论文写作提取与核验报告_模板.md`，把「代码 / 结果 / 数据」翻成「能写什么」。
4. **钉证据**：复制 `04/证据与待确认清单_模板.md`，一条主张一条证据。
5. **写正文**：按 `01` 规范 + `04/论文阅读指南_模板.md` 落笔到官方 Word 模板。
6. **提交前**：过一遍 `03` 验收清单，再导出 PDF 逐页检查。

## 约定

- 本仓库只含「方法论 + 空模板」，**不含**任何具体赛题、论文正文、官方原文件、建模代码与数据。
- 官方模板与章程请从官网自取（见 `05`），本仓库不转发以规避版权。
- 所有模板的占位符（`…`、`（示例）`、`E01` 等）需按当届项目实际填写。
