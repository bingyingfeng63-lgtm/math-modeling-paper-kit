# 证据与待确认清单（模板）

> 用途：在写作前/中，把「论文主张」逐条钉在「证据」上，防止出现无对照的结论、占位范围或过时数字。
> 使用方法：复制到当届项目目录，逐条填写；「主张核验」是核心，一条主张一行。

## 一、证据目录

| 编号 | 证据 | 主要用途 |
|---|---|---|
| E01 | 题目 PDF 与前置分析 | 确认边界、决策、指标、硬约束 |
| E02 | 材料包 README | 确认材料结构与作者自述 |
| E03 | 阅读指南 / 核心模板 | 提取代码—论文映射、符号、公式 |
| E04 | 主代码 | 核对实际算法、权重、评价口径 |
| E05 | 结果表（汇总 / 明细 / 逐时） | 核对指标与逐时结果 |
| E06 | 原始数据附件 | 复核期限、容量、功率等参数 |
| E07 | 图表目录 | 检查数值、内容、可读性 |

## 九、论文手的下一步

1. 直接采用阅读指南中已核验的问题分析、公式、算法表述和结果段落。
2. 用三线表重做核心指标，不插入图片型指标表。
3. 在讨论结尾明确方法局限（启发式 / 缺对照 / 未做敏感性分析等）。
4. 收到基准或消融结果后，再补写「降低、提高、有效、稳健」等比较性结论。
