# 论文阅读指南（模板）

> 用途：把「代码」翻译成「论文段落」，让论文手不看代码也能快速定位每段该写什么、对应哪几行代码。
> 使用方法：针对主代码文件，先给目录结构概览，再分「快速阅读」与「精读」两遍写。

## 目录结构概览

```text
主代码文件名
├── 第1部分：配置与数据加载（L1—L100）
├── 第2部分：核心算法逻辑（L102—L210）← 方法论
├── 第3部分：求解 / 调度流程（L212—L350）← 算法设计
├── 第4部分：主流程与实验设计（L352—L470）
├── 第5部分：结果评估（L472—L560）← 实验结果
└── 第6部分：保存结果（L562—L620）
```

## 第一遍快速阅读：看这几个部分

| 代码位置 | 部分 | 作用 | 论文中用途 |
|---|---|---|---|
| L1—L5 | 文档字符串 / 版本说明 | 版本与修复点 | 摘要 / 引言 |
| … | 核心类 / 函数 | 约束检查、资源分配 | 方法论 |
| … | 主流程 | 算法策略 | 方法论 / 实验设计 |
| … | 结果评估 | 统一口径复算 | 实验结果 |

## 第二遍精读：论文各部分对应内容

### 1. 论文摘要部分

- 看代码开头注释（版本说明、解决的问题、关键指标）。
- 摘要只写：问题、方法、关键结果，不写过程细节。

### 2. 问题分析 / 模型建立部分

- 看配置与数据加载：提取变量、单位、参数；
- 看核心类：提取约束条件与目标函数；
- 每个符号、每条约束回指到代码行号。

### 3. 模型求解 / 算法部分

- 看主流程：写出算法步骤（阶段、回退、候选搜索）；
- 注明「启发式」还是「精确求解」，不越界声称最优。

### 4. 实验结果部分

- 看结果评估：只引用统一口径复算后的精确值；
- 图表优先用三线表或高质量图，不贴代码截图。

### 5. 局限与讨论部分

- 看算法里未做敏感性分析 / 缺基准对照 / 硬编码 / 边界未收紧的地方，逐条写进局限。

## 附：常见「代码 → 论文」映射速查

| 代码里的东西 | 论文里对应 |
|---|---|
| 文档字符串 / 注释里的版本说明 | 摘要、引言 |
| 参数定义、单位 | 符号表、模型假设 |
| `if` 约束判断 | 约束条件公式 |
| 目标函数 / 评分函数 | 目标函数公式 |
| 主循环 / 阶段 | 算法流程（文字 + 流程图） |
| 结果汇总输出 | 结果表格 |
| 硬编码路径 / 常量 | 工程说明（通常不进论文，或作为局限） |
